# Design choices and where to see them

Each choice that the Tenancy pages describe, with three pointers: the **code**, something to **try** on the running
[sample](../the-sample.md), and a **test** that fails when the choice is undone.

- **Try it** names one of these:
  - a preset of the UI's Try it page, by its id in
    `DevAttempts.cs`;
  - a UI page;
  - a request in the host's `.http` file,
    marked (`.http`) and listed under the person who sends it;
  - a command.

  [Try it](try-it.md) explains how to start the sample.
- **Test** names a test class under `Tests/`. The sample's tests are in `Tests/Examples.Tenancy.Tests`. A test that
  needs the host with a database takes it from the fixture `SampleHosts`, and needs Docker.
